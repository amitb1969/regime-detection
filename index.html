DL Partners — Regime Detection Engine v2.1
Internal documentation for research team — April 2026
This model uses a Weight of Evidence (WOE) framework across four orthogonal pillars: Market Structure, Risk Appetite, Volatility Regime, and Liquidity. Each pillar scores 0–100 continuously — there are no binary regime switches. The three pillars are genuinely independent: a market can be Trending + Risk-Off + High Vol simultaneously (2022). Treating them as mutually exclusive (as 6-state models do) discards real information. The composite state is the intersection of four pillar scores, not a single majority vote.
A 3-day persistence filter (Hamilton 1989, Markov regime-switching) prevents whipsawing at boundaries. A pillar must hold a new state for three consecutive readings before the label flips. Raw scores and filtered scores are shown separately in the model view.

Scoring formula
# Each signal is min-max normalized to [0,1] within its historical range
def norm(value, lo, hi): return clamp((value - lo) / (hi - lo), 0, 1)

# Pillar score = weighted sum of normalized sub-signals (weights sum to 1.0)
pillar_score = Σ (weight_i × norm_i) × 100 # outputs 0–100

# Persistence filter: hold previous state unless new state holds for 3 days
if all(hist[-3:] in same_state): confirmed_state = current_state
else: confirmed_state = prev_confirmed_state

# Portfolio sizing: vol and liquidity penalties applied multiplicatively
liq_penalty = max(0, P4_score - 40) × 1.5
vol_penalty = max(0, P3_score - 50) × 1.2
size_scale = clamp(1.0 - (liq_penalty + vol_penalty) / 100, 0.15, 1.0)

import pandas as pd, numpy as np
from hurst import compute_Hc
import ta

spy = yf.download("SPY", period="3y")
ret = spy['Close'].pct_change()

H, c, data = compute_Hc(spy['Close'].dropna(), kind='price', simplified=True)
autocorr = ret.rolling(63).apply(lambda x: x.autocorr())
amihud = (ret.abs() / spy['Volume']).rolling(21).mean()
bid_ask_proxy = (spy['High'] - spy['Low']) / spy['Close']
vol_z = (spy['Volume'] - spy['Volume'].rolling(63).mean()) / spy['Volume'].rolling(63).std()
